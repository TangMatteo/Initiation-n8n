# n8n Mini Projects

Ce repository regroupe quatre mini-projets réalisés dans le but de découvrir et expérimenter l’outil d’automatisation n8n. Chaque projet met en pratique différents concepts tels que l’intégration d’API, l’automatisation de workflows, et l’utilisation de l’intelligence artificielle.

## Objectifs

- Comprendre le fonctionnement de n8n
- Manipuler des APIs externes
- Automatiser des tâches simples
- Expérimenter des cas d’usage concrets

## Projets

### 1. Météo intelligente

Ce projet utilise une API météo pour récupérer des données en temps réel et fournir des informations pertinentes selon le contexte.

Fonctionnalités principales :
- Appel à une API météo
- Traitement des données reçues
- Réponse contextualisée selon la situation


### 2. QCM interactif

Un système de quiz automatisé permettant de poser des questions et de gérer les réponses.

Fonctionnalités principales :
- Génération de questions
- Vérification des réponses
- Logique conditionnelle pour adapter le flux


### 3. Générateur d’emoji aléatoire avec IA et bot Discord

Ce projet combine intelligence artificielle et automatisation pour générer des emojis aléatoires et les envoyer via un bot Discord.

Fonctionnalités principales :
- Génération d’emoji via IA
- Automatisation avec n8n
- Intégration avec Discord


### 4. Générateur de citations

Un workflow simple permettant de générer et diffuser des citations.

Fonctionnalités principales :
- Génération de citations
- Automatisation de l’envoi ou de l’affichage


## Installation

1. Cloner le repository :

```
git clone <url-du-repository>
```

2. Installer et lancer n8n

3. Importer les workflows dans n8n


## Utilisation

Chaque projet peut être utilisé indépendamment. Il suffit d’importer le workflow correspondant dans n8n et de configurer les variables nécessaires (API keys, tokens, etc.).
